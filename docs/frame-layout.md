# 相纸边框

边框按批准的 R3 设计移植。照片不缩放、不裁切；成品比例控制照片外面的整张画布。

`finish/frame_core.py` 的整数求解器与 `web/assets/finish_frame_core.js` 一一对应。样式先生成照片、边沿和文字组成的单元，再找满足最小留白的最小整数比例画布。固定比例通常至少留 6% 侧边和顶边；电影为 5%；白边的细、中、粗分别留 6%、9%、13%。单元按各样式的光学中心定位。

字体从成品宽高计算，按 SFNT 字形框计算大写 H 的高度。Inter SemiBold 的主行、Inter 的次行和实际 RICOH 标志按设计对齐。胶片边印按真实胶片比例取字号，不套正文下限。中文使用系统字体，与同一行的拉丁字共用基线，不加字距。

绘制项按底层、照片、上层排序。Python 和 Canvas2D 使用相同的矩形、圆角、阴影、孔洞、线、文字、旋转文字和多边形数据。胶片孔洞复制灯台背景，竖幅胶片的整个单元转 90°，照片保持原方向。拍立得原比例的画布就是相纸；固定比例在石色背景上绘制带阴影的相纸。

样式顺序为徕卡水印、模糊背景、白边、哈苏水印、拍立得、胶片、极简细线、电影宽银幕、展签、幻灯片、暗房相纸、邮票齿孔。`frame_new.py` 与 `finish_frame_new.js` 加入后七款，复用原来的求解器。

模糊背景从编辑、调整、裁剪后的照片生成：缩到 1/8、强高斯模糊、放大，饱和度乘 1.15，亮度均匀乘 0.90。浏览器在预览尺寸先生成当前比例的背景，其余比例与参数开关只在边框面板可见且空闲时逐张预热；舞台和卡片共用缓存，点边框选项不重新模糊、不请求服务器出图。只有模糊背景正在使用或边框面板可见时才取底图。拖动调整滑块时沿用上一张底图，松手并且最新预览稳定 120 毫秒后才刷新一次。隐藏卡片不触发显卡回读；装饰缓存命中时也不再预热背景。

暗房相纸的 `carrier` 绘制项保存尺寸、厚度和种子，导出时展开成参考实现的有机轮廓。纸纹用种子 42，轮廓用 19790324；两者均由代码生成，导出可重复。浏览器在预览尺寸生成确定的纸纹和轮廓，用便携随机数发生器；纹理噪点不与 NumPy 逐像素对齐。邮票的齿孔用抗锯齿圆盘绘制。

## 设置

边框 JSON 使用 `version: 2`，包含 `style`、`color`、`weight`、`show_logo`、`show_params`、`show_date`、`text`、`output_ratio`、`fmt`、`table`。

- `film.fmt` 是 `135` 或 `120`，`table` 是 `light` 或 `black`。
- `instant.fmt` 是 `polaroid`、`instax_square`、`instax_wide` 或 `instax_mini`。
- 徕卡、哈苏默认显示日期；拍立得默认不显示日期。文字默认留空。
- 极简细线默认米白，可选白、黑；展签可选白、黑、米白；幻灯片可选米白、黑。电影、展签和暗房使用用户文字；空文字不填入虚构内容。模糊背景可关闭参数。
- 旧版或非法的已存边框回到出厂“无边框”，不影响照片的其他编辑。下一次写入 sidecar 时清掉旧边框键。
- 新请求里的未知键、非法画幅、比例或显示开关返回中文错误，不按旧语义猜测。没有边框设置时继续继承默认值。

复制、粘贴和撤销按整块边框设置传递，成品尺寸接口与导出共用布局。

## 对照

`tests/golden/frames_r4.json` 保存批准参考实现的 11,424 个合成布局摘要。覆盖六种照片形状、全部八个成品比例、全部有效选项组合、空白和 24 字文字、完整和缺失拍摄信息。`test_frame_reference.py` 在任何 CI 环境验证摘要；本地有设计参考脚本时还逐字段对照，不存在时只跳过这项。Python/JS 逐项对照另外覆盖所有这些组合及中文。轮廓独立展开后与原参考逐点对照。

参考适配只压缩轮廓，并明确修正两处与 DESIGN 不符的代码：照片原比例也保留模糊背景；邮票题铭使用实际镜头焦距，未知时省略，不一律印 50。其余布局数字直接对照参考。真实照片导出另与批准图或原参考渲染器比较。

重新生成参考摘要：

```bash
uv run --frozen python -I scripts/frame_reference.py --reference /path/to/frame-design
```

真实照片和对照图不进仓库。自定义标志和拼图另行开发。

# 完整本机配方

完整拟合优化独立的R、G、B曲线、C100矩阵和对称扇区，输出一个552字节记录。`native-C040-v2.0`、输入映射和原厂04来自已导入的校准数据，不重新迁移，也不叠加IN6w。原生相机01到04仍由既有相机数据路径读取。

## 保存和质量状态

RecipeRepository独占长期记录、单元绑定、模型和控制快照、来源、准入证据、已归档候选和名称。SQLite短事务经私有目录原子发布。求解期间不持数据库写锁。

候选与已保存配方使用同一个`kind:local`引用和resolver。保存只增加名称，不改变记录或质量状态。隐藏名称不删除内容，照片、旋钮记忆和撤销仍能读取旧版本。清理job或删除原LUT也不删除版本，冻结署名不随LUT修改。

| 状态 | 含义 |
|---|---|
| 计算完成 | 结构合法的记录和评估回执已归档。 |
| 已保存 | 具名引用已原子提交。 |
| `needs_evidence` | 必需来源、分组或回执未齐。 |
| `rejected` | 至少一项数值门失败，仍可同时列出缺证据。 |
| `passed` | 该记录在冻结上下文的全部适用门通过。 |
| `historical_exception` | 匹配正式七份授权及摘要，保留原准入未通过项。 |

未准入但合法的记录可明确保存为本机草稿，并在本机预览、套用和导出。取消、中断、来源损坏或记录格式无效的结果不能保存。工作室不提供写卡功能。

## 私有质量输入

标定包提供预测模型，质量包提供训练和独立留出，两者不能相互代替。产品只读取明确导入的质量包，不读取开发机研究目录，也不执行包内代码。

`gxr-studio/quality-pack/1`以`quality-pack.json`列出成员名称、长度和SHA256。包保存冻结模型、原白平衡码值`raw_wb`、映射后码值`x`、场景XYZ、目标`want`、原厂04预测`base_new`、权重`sw`、逐点`photo_id`和ISO。浮点数组固定为小端float64，索引和ISO固定为小端int64，NPZ禁止pickle。

训练、ISO200主留出和其他ISO留出按照片及配对家族隔离。相同RAW的复制文件不能跨训练和留出。照片元数据保留RAW、JPG、家族及采样回执的摘要、场景和ISO。缺场景或其他ISO保留为质量缺项；没有训练数据就不启动。

原优化参照、原厂04和适用替换参照是不同角色。同风格版本发布后，新拟合自动绑定它作为替换参照。发布时若现行版本已变化，拒绝旧结果覆盖，保留候选供查看。

封存数值来源包使用`gxr-studio/sample-source/1`。`source.json`列出`environment`、`references`、`photos`、`sources`、`slot`、`family`、`groups`和带SHA256的`files`。每个分组NPZ含`raw_wb`、`xyz`、`sw`、`photo_id`和`iso`五个数组。`family`明确为`color`或`bw`，不会因目标接近灰色而自动变成黑白。

在已安装环境中构建私有语料包：

```sh
uv run --frozen python -I -m gxr_studio.fit_contexts /private/sampling-source /private/new-quality-pack
```

该命令核对封存来源及固定数组后生成`sample-corpus`质量包。LUT生成时，再用同批原厂04预测、XYZ和完整空间解释构造目标，保存LUT原字节及摘要。已经绑定目标的冻结质量包不能换LUT后沿用旧`want`。输入数组从不可变字节构造，求解器只获得训练输入，没有留出加载器或路径。

## 求解和准入

产品预声明`full-reference-fit/1`路线，用SciPy reference TRF/SVD运行iterate和exact。它不执行研究的私有fast kernel。两个阶段均固定`max_nfev=160`及原容差，保留每个起点、边界、配置、终止和收敛回执。每个起点编码固定33点整数回溯，用加权D65 ΔE00平方目标及固定夹具选定唯一胜者。留出结果不追加起点，也不选择第二名。

评分沿用冻结顺序和`np.rint`。独立展开的前向仅作交叉核对。求解同时包含原厂04色度查表对曲线导数的额外项，不优化额外gains、offsets或tint。

所有适用门取AND，包括CRC和域、输入映射一次、整数训练目标及重算、全部exact起点、固定梯度与无新增色相反转、ISO200主留出、场景、其他ISO、近零分母，以及两种次序乘三个通道各四相位的128个唯一量化分支。替换和额外原参照分别运行适用检查。缺分支、重复分支或`partial`不能通过。

相似度为`100 × (1 − 配方ΔE00中位 / 原厂04ΔE00中位)`。D65分母小于0.25的照片使用绝对中位和P95门，相似度为未定义。没有统一的95%准入线。

## 选择与成片

sidecar保存服务返回的`local`版本引用、单元、控制底子和档位，不保存`builtin + levels`替代身份。照片保存及粘贴继续使用原有rev检查。候选、保存版本、CPU和GPU通过同一个resolver取得实际entry及冻结模型。

记录SHA与调整后entry SHA分开。默认控件返回被评记录；额外调整改变entry后，质量提示明确表示当前调整未评估。渲染缓存包含模型绑定，换当前相机数据不会替换已保存版本的模型。当前程序不支持其算法契约或依赖损坏时直接失败。

完整本机配方只支持既有RAW+JPG业务。显式选择后，RAW解码、模型或记录失败不会改用相机JPG并称套用成功。实际导出走CPU RAW成片链，返回`recipe_binding`中的记录、entry和模型绑定摘要。此路径沿用当前烘焙导出，不扩大`precise`承诺。

50mm实拍校准范围仍为ISO200及1600，28mm和MOUNT为ISO200。其他ISO留出是主模型迁移诊断；28mm和MOUNT的曝光沿用50mm，28mm ISO100限制仍保留。电脑预测和合成验证均不代表相机验收。

旧`my-recipe/1`文件保留，不迁移成完整记录。页面提示重新生成。历史DAT解析及既有相机原生记录继续保留自己的语义。

# 图库交互约定

图库以照片为主，沿用现有深灰背景、字体、蓝色选择框和紧凑的日期分组。缩略图默认铺满固定的 3:2 格子，加载和切换显示方式都不改变格子的尺寸。“完整显示”保留宽幅和竖拍的整个画面，选择记在本机。

`Library.list_shots()` 是排序的唯一来源。日期从新到旧，同日按拍摄时间从新到旧，同一时刻按文件名和照片 ID 固定顺序。未知日期放最后。日期栏封面、分页、网格键盘导航和编辑器上一张、下一张沿用这份顺序。

普通点击始终打开照片。左上角勾选、⌘ 点击和空格切换选择，⇧ 点击和 ⇧ 方向键按网格顺序连选。打开照片后回图库保留选择。切日期清空选择，提示清空的张数，并保留“恢复选择”，直到用户恢复或关闭提示。恢复时回到原日期筛选，只恢复仍在图库中的照片。Esc 清空选择。

顶栏导出按钮在有选择时显示选中张数，在筛选某一天且没有选择时显示日期和当天总数。全部照片且没有选择时，点击导出继续提示先选照片。图库不显示 HDR 角标，信息面板说明已生成的 HDR，导出面板保留 HDR 选择。“编辑过”和只有单一文件格式的角标仍显示。

导入任务的 `state` 保留原来的生命周期。`phase` 只说明正在核对内容还是复制文件。存储卡标签、导入面板和相机页共用 `progressLine()`：核对已有文件显示“正在检查 n/N”，复制显示“正在导入 n/N”，最后整卡核对另行提示。结果分别列出新导入、补全和已在图库的数量。是否能说“都已导入”仍由内容核对结果决定。

行为测试在 `test_busy.py`、`test_api.py`、`test_import.py`、`test_import_summary.py` 和 `test_feedback_copy.py`。`test_library_browser.py` 复用现有真服务器和浏览器驱动，实际点击、按键，并用截图边缘像素对照源缩略图，验证铺满格子的画面。

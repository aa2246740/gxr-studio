# 图库锁和坏掉的边车

同一个图库只能有一个工作室。锁是 `<图库>/.studio/studio.lock` 上的 flock。进程没了，系统会放开。不要为了「解开」去删照片目录。

索引坏了或想丢掉缓存：在页面上重建，或 `POST /api/library/rebuild`。这只删索引，不删照片。`library_rebuild` 开关如果被写成 false，接口会 403，把应用数据目录里的 `flags.json` 改回去或删掉。

边车（`*.gxrs.json`）读不出来时，读接口当作没有编辑并在响应里带 `warning`。写接口会把坏文件改名为 `.corrupt-<时间>` 再重建。看到这个后缀，说明上一份编辑记录留在旁边，照片还在。

# 拍立得印记落点

「时间戳」在拍立得边框下提供「照片上 / 拍立得边框上」。默认仍放在照片上。
边框上的印记排在照片和边框题字下方，字体、颜色、四角位置和发光继续沿用时间戳设置。
改用其他边框时，印记放回照片上；再次选择拍立得时恢复底边落点。

`stamp.placement` 只接受 `photo` 和 `border`。缺省按 `photo` 处理，序列化默认值时不补这个键，
旧编辑继续走原来的盖戳、加框顺序。新选项先加框，再在底边盖戳；HDR 的照片区域不受影响。

底边版面在 `finish/layout.py` 和 `web/assets/finish_layout.js` 使用相同算式，预览和导出都按全尺寸坐标绘制。
底边的坐标属于整张成片，照片上的坐标属于照片。底边从照片及题字墨迹的下沿开始，给发光预留空间。

`test_stamp_border.py` 核对照片像素、题字间距、HDR 区域和旧编辑的 JPEG 字节；
`test_finish_layout_parity.py` 对照字号、四角、字体、发光、题字和横竖尺寸；
`test_stamp_border_browser.py` 从真实面板选择落点，检查保存结果和舞台叠加层。

# GXR 电脑工作室 1.0.0

2026-11-13 发布的第一个正式版本，只支持 macOS。

## 能做什么

- **插卡导入：** 插上存储卡，照片自动读进来，按拍摄日期排好。卡上的文件一个都不会改。每张照片都核对过内容，确认已经在图库里，才提示「可以安全弹出卡了」。
- **套配方，看电脑预测：** 导入卡上的相机配方文件，配方页每个配方显示成一张卡片，预览的是当前照片套上这个配方的样子。点一张卡片，就换成这个配方。
- **调整：** 曝光、白平衡、对比、高光、阴影、黑点、饱和度、自然饱和度、暗角，以及主曲线和红绿蓝曲线。直方图随滑块实时变化，死黑和死白可以在照片上标出来。
- **裁切：** 支持 XPan 65:24 等成品比例。
- **LUT：** 导入 `.cube` 文件。输入色彩空间按文件里写明的来；没写明时根据文件名、标题或注释推测；判断不出来时先用 sRGB 并提示你核对，有冲突或不支持时需要手选。
- **边框、logo、日期戳：** 可以选边框样式，用自己的 logo，加日期戳。
- **HDR：** 有 RAW+JPG 的照片可以导出带增益图的 HDR JPG，在支持 HDR 的屏幕上显示高光。检查不通过时改为导出普通 JPG，并说明原因。
- **批量：** 一张调好后复制调整，在图库里选很多张，一次粘贴上去，粘贴完可以整批撤销。
- **导出：** 尺寸有原始、大、中、小四档，品质有高、中、低三档。
- **显卡预览：** 浏览器和当前照片都支持时，拖动滑块由显卡实时重画；不支持时自动改用普通预览。显卡画面和导出用的算法逐像素对拍过，差别控制在测试门槛以内。

## 怎么开始

1. 在本页下载「Source code (zip)」，解压。
2. 双击 `GXR Studio.command`。第一次会自动安装依赖，要联网，大约一两分钟。如果提示「没有找到 uv」，打开「终端」运行一次 `brew install uv`。
3. 把相机的存储卡插进读卡器。

详细说明见 README。

## 需要注意

- 「电脑预测」要用到相机数据和校准数据。相机数据从卡上导入；校准数据目前只有开发机能做。没有校准数据时，配方颜色不可用，其他功能照常。
- 所有东西都在你自己的电脑上，不联网，也不往存储卡上写任何东西。
- Windows 版暂停适配。

## 已知问题

- 需要重新渲染的照片导出 JPG 时会被压缩两到三次，颜色鲜艳的细边会略软；没改过、直接沿用相机 JPG 的照片压缩一到两次。将在 1.0.1 修复，改成只在最后压缩一次。

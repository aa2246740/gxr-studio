# 导出关机图（GXROFF.JPG）

理光 GXR（固件 g260）关机画面读取存储卡最外层的 `GXROFF.JPG`（与 `GXRCE.DAT` 同级）。固件对该文件的 JPEG 结构要求固定，常规相册保存或通用 JPEG 编码器往往会被相机拒收。

## 格式与校验规则

生成的 `GXROFF.JPG` 满足以下全部条件，且导出前由同一套严格校验器放行：

- 像素尺寸：固定 640×480（铺满居中裁切，先按 EXIF 方向转正，透明通道铺在纯黑背景上，带 ICC 配置的图片转到 sRGB）。
- 文件体积：不超过 32,768 字节；按固定品质阶梯从 92 逐步下探（92, 88, 84, 80, 75, 70, 65, 60, 55, 50, 45, 40, 35, 30, 25, 20, 15, 10），命中即停。
- 精确段序：`SOI` → 单个 `DQT`（130 字节，含 8 位表 0 与表 1）→ `SOF0`（640×480，基线 4:2:2，Y `2x1`、Cb `1x1`、Cr `1x1`）→ 单个 `DHT`（固定 ITU-T T.81 Annex K.3 四张表 `DC0, DC1, AC0, AC1`）→ `DRI 40` → 标准 `SOS` → 扫描数据（59 个按序轮转的 `RST0–7`，60 段 × 40 MCU）→ 紧贴文件末尾的 `EOI`。
- 不含 `APP`、`COM`、`EXIF` 等附加段，尾部无多余字节。
- `make_off_image.py --check FILE` 校验通过时输出 `J7`。

## 桌面端与手机端实现

- 桌面端（Python，`src/gxr_studio/off_image.py` 与 `src/gxr_studio/api/off_image_routes.py`）：完全运行在进程内（Pillow 基线 4:2:2 + `restart_marker_rows=1` + 纯 Python remux 与校验），不依赖外部二进制，macOS 与 Windows 同口径。编辑器顶栏导出按钮旁提供菜单入口「做成关机图…」，支持预览最终字节、使用「换一张图…」替换为任意图片、显示大小与品质，并沿用桌面导出路径安全检查。
- 手机端（Rust WASM，`core/crates/gxr-export/src/off_image/` 与 `mobile/src/app/off_image_sheet.ts`）：在独立的短命 Worker 中完成解码、Lanczos 缩放裁切、纯整数 4:2:2 + DRI 40 编码与严格校验，完成后立即终止 Worker 回收线性内存。入口位于编辑器顶栏 `⋯` 菜单「做成关机图」，导出走系统共享表（提示选「存储到“文件”」，避免进相册重压缩）或下载兜底。

## 卡安全

GXR 电脑工作室绝不向任何相机存储卡写入文件。桌面端导出前校验目标目录，拒绝已挂载相机卡、卷根目录、图库目录与仓库目录；手机端只输出用户通过系统共享保存的 `GXROFF.JPG`，由用户手动拷贝到存储卡最外层。

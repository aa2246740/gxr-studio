# 成品比例

摄影师选择社交平台比例后，导出的照片连同边框一起保持该比例。范围是边框面板、舞台、样式预览和导出尺寸；沿用现有字体、颜色、分段按钮和密度。单人实现，避免改动并行的配方、图库和 LUT 页面。

- 白边、徕卡、哈苏、胶片、拍立得默认「跟裁剪」，旁边显示当前比例，例如 3:4；「边框原样」保留样式原来的留边。
- 原始和自由裁剪没有固定比例，两种选择都保留原有版面。旧 sidecar 缺少 `keep_ratio` 时按默认规则处理。
- 先按样式算出最小留边，再把照片与文字作为一个整体居中补到比例。照片不缩放、不二次裁切；文字、标志和参数栏跟着照片移动。
- 全尺寸画布取比例的最小整数倍。导出尺寸档沿用原来的长边缩小规则，非整数比例允许最后一步像素舍入。
- 画布保留已有比例及其旧版舍入，新增严格 3:4 和 2:3，以免改变原始或自由裁剪的既有导出字节。
- 成品尺寸放在「边框」标题旁，先显示像素，再显示适用的比例，选样式时不用滚动就能看到。尺寸查询只跟照片底图、几何与裁剪相关；边框点击不重新查询或渲染服务器图片。失败时给重试，不展示估算值。
- 舞台、样式卡和尺寸行共用全尺寸裁剪框，避免预览放大倍数的舍入改变边框版面。配方旋钮不改变尺寸，不触发新的查询。
- 导出对话框等当前保存队列后读取尺寸，切尺寸档直接换数字；导入相机数据后重新读取，旧查询不会盖掉新结果。批量说明每张照片按各自比例导出。

# 成品比例

边框面向发布场景：用户选成品的横竖比例，照片及其裁剪不决定成品比例。新边框默认 3:4；「设为默认」可保存自己的选择。

- 所有边框共用「成品比例」：1:1 方图、4:5 Instagram 竖图、3:4 小红书、2:3 竖幅、9:16 快拍与短视频、16:9 横屏视频、3:2 横幅、照片原比例。方向固定，不随照片旋转。
- 照片保留全尺寸像素，不缩放、不再裁切。先算样式的最小边框和字幕条，再用所选比例的最小整数倍补画布。额外空间居中，字幕和标志跟着照片移动。横图放入 9:16 时，上下大片留白是预期行为。
- 「照片原比例」保留样式原来的等宽边或字幕条，等于主分支的 `keep_ratio=false`；成品自身比例仍包含边框。它不强制成品与照片宽高比相等。
- 画布与「白边 · 中」重复，已移除；两组旧比例选项也已移除。只保存 `output_ratio`，不解释或迁移旧比例值。
- 含 `keep_ratio`、`canvas_ratio` 或旧画布样式的边框设置整组重置为出厂默认：无边框，下一次选边框时为 3:4。sidecar、保存的默认值、粘贴来源和浏览器一致；新的保存不会带旧键。
- 全尺寸成品精确满足所选比例。导出的尺寸档最后按长边缩小，允许 1 像素舍入，不按社交平台像素尺寸重采样。
- 边框面板在本机用共享版面立即更新成品尺寸；导出对话框按同一版面和尺寸档计算。每次边框选择不请求服务器出图。

`tests/test_output_ratio.py` 验证所有样式、比例、横竖方图、XPan 和 9:16，以及像素与字幕位置。`tests/test_finish_layout_parity.py` 逐项对照 Python 和 JS。
`tests/test_output_ratio_real.py` 用现场照片走导出管线，比对显示尺寸和文件，并与冻结主分支 `0d3b08d` 比较「照片原比例」的 JPEG 字节。样本和导出不进仓库。
